## Overview

Autonomous vehicles (AVs) are being deployed as robotaxis across U.S. cities. Regulators, manufacturers and the public need clear evidence on what kinds of incidents occur and under what conditions.

This project cleans and explores federal AV incident reports to answer one question:

> **Which environmental and roadway factors are most associated with RoboTaxi crashes?**

The target variable is **Crash Interaction Type**, grouped into three categories: *Motor Vehicle*, *Fixed Object* and *Non-Motorist / Other Road User*.

## How the notebook is organised

The notebook follows the analysis pipeline, and the code is encapsulated in classes so each step can be re-run or reused on its own.

| Class | Responsibility |
|---|---|
| `EnvironmentSetup` | Applies pandas, seaborn and warning settings. |
| `IncidentDataLoader` | Loads the raw CSV and provides info / descriptive-statistics views. |
| `AVIncidentCleaner` | One method per cleaning step: drops irrelevant column groups, combines roadway and weather flag columns into single features, groups `Crash With` into the target variable, and saves the cleaned file. |
| `DatasetCompletenessReport` | Draws the before-and-after data completeness chart. |
| `IncidentVisualizer` | One method per chart (see below). |

### Cleaning summary

- **116 → 14 columns.** Removed administrative, identification, source, severity, contact-area, data-availability, location, date/time and narrative columns.
- **Feature engineering.** The roadway-condition and weather-condition flag columns were merged into `Roadway_Conditions` and `Weather_Conditions`.
- **1,365 → 1,257 rows.** Removed incidents whose `Crash With` value was *Other, see Narrative*.

## Key findings

- **About 92% of crashes** involve another motor vehicle; fixed objects (≈6%) and non-motorists (≈3%) are rare.
- Crashes are mostly **low-speed events**: roughly two-thirds occur at 0 to about 3 mph, and the median pre-crash speed is 0 mph.
- About **half of crashes happen while the RoboTaxi is stopped or parked**, so it is usually the vehicle being hit.
- **Roadway type and the vehicle's own movement** separate crash types best (for example, fixed-object crashes occur only while moving, and are common in parking lots). **Weather** does not meaningfully change the crash-type mix.
- Model year shows only a weak, inconclusive trend in mean pre-crash speed.

Detailed insights for every graph, and a final insight for the presentation, are written in the notebook after each chart and in its Conclusion section.

## Limitations

- **Counts, not rates.** There is no exposure data (miles driven, time in each condition), so higher counts do not imply higher risk.
- **Reporting bias.** One operator accounts for most of the raw reports.
- **Class imbalance.** Only 70 fixed-object and 33 non-motorist incidents limit what can be concluded about them.
- **No fault information** is recorded, and narrative text was not analysed.

## Possible next steps

1. Test the associations formally (chi-square / Cramér's V for categorical factors, Kruskal–Wallis for speed).
2. Build a classifier that handles class imbalance (stratified split, class weights or resampling, macro-F1).
3. Normalise by exposure where possible and analyse the narrative text with NLP.
